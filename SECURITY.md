# Security Policy

UMP controls communication between physical machines, so security defects may have physical consequences. Do not open a public issue for a suspected vulnerability.

The project is pre-release and does not yet have a dedicated disclosure mailbox. Contact the repository owners privately until one is published. Include affected versions, reproduction steps, impact, and any suggested mitigation.

No current release is approved for unsupervised physical-machine control. Development credentials and simulated safety messages are not production safety controls.
