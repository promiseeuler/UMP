| Command | Purpose |
| --- | --- |
| `ump-demo` | Run the basic semantic collaboration demo |
| `ump-node` | Start or preflight a robot participant |
| `ump-coordinator` | Preflight, submit, and inspect collaborative runs |
| `ump-inspector` | Serve the read-only operational UI |
| `ump-deployment` | Generate and verify local network bundles |
| `ump-network-config` | Validate secure network configuration |
| `ump-network-diagnostics` | Inspect network health without message content |
| `ump-credentials` | Enroll, activate, rotate, inspect, and revoke identities |
| `ump-authority` | Grant, inspect, audit, and revoke authority leases |
| `ump-goal` | Validate shared goals and goal batches |
| `ump-vocabulary` | List and validate capability contracts |
| `ump-conformance` | Run UMP 0.1 protocol vectors |
| `ump-adapter-conformance` | Inspect and verify manufacturer adapters |
| `ump-integration` | Validate config, inspect mappings, and check runtimes |
| `ump-reconcile` | Resolve unknown outcomes with operator evidence |
| `ump-benchmark` | Run process-local and TLS reference benchmarks |
| `ump-lan-benchmark` | Measure the two-host network path |
| `ump-lan-evidence` | Produce and verify LAN evidence |
| `ump-lab` | Run scenarios, profiles, faults, load, and soak |
| `ump-readiness` | Generate and verify signed readiness reports |
| `ump-ops` | Create, verify, and restore durable-store backups |

Use `COMMAND --help` and `COMMAND SUBCOMMAND --help` for the authoritative arguments supported by the installed build.
