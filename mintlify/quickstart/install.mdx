Install the Universal Machine Protocol Python reference implementation from the GitHub repository. The core requires Python 3.11 or newer, Git, and macOS or Linux. Optional lab dependencies add WebSocket, MQTT, and OPC UA support for container-based scenarios.

## Prerequisites

Before installing, confirm your environment meets these requirements:

- **Python** 3.11 or newer
- **Git**
- **macOS** or **Linux**
- **Docker Desktop** (macOS, including Apple Silicon) or **Docker Engine with Compose** (Linux) for container-based lab scenarios

ROS 2, Gazebo, MQTT, and OPC UA runtimes are optional and lazy-loaded. They are only needed when you run the corresponding integration or Docker profile.

## Install UMP

<Steps>
  <Step title="Clone the repository">
    Download the UMP source code and enter the project directory:

    ```bash
    git clone https://github.com/promiseeuler/UMP.git
    cd UMP
    ```
  </Step>
  <Step title="Create an isolated environment">
    Create a Python virtual environment and activate it to avoid conflicts with system packages:

    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    python3 -m pip install --upgrade pip
    ```
  </Step>
  <Step title="Install the core">
    Install the UMP core package. For lab scenarios and transport probes, also install the optional extras:

    ```bash
    # Core only
    python3 -m pip install .
    
    # With lab dependencies (WebSocket, MQTT, OPC UA)
    python3 -m pip install '.[lab]'
    ```
  </Step>
  <Step title="Verify installation">
    Confirm the CLI tools are available by checking their help output:

    ```bash
    ump-demo --help
    ump-lab --help
    ump-readiness --help
    ump-ops --help
    ```

    Each command should print its usage, subcommands, and options without errors.
  </Step>
</Steps>

## Optional runtimes

Some standards integrations require additional Python packages that are not installed by default:

| Integration | Required package | Check command |
| --- | --- | --- |
| VDA 5050 | `paho-mqtt` | `ump-integration runtime vda5050` |
| Open-RMF | `rclpy` | `ump-integration runtime open_rmf` |
| ROS 2 | `rclpy` | `ump-integration runtime ros2` |
| OPC UA Robotics | `asyncua` | `ump-integration runtime opc_ua` |

You can verify a runtime without starting a robot node:

```bash
ump-integration runtime vda5050
```

If the runtime is missing, the command returns `IntegrationUnavailableError`. Install the missing package with `python3 -m pip install <package>` and retry.
