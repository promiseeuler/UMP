# UMP Construct Explainer

Concept: a live evidence rail that keeps simulated robot motion and UMP's shared state visible together.

- Canvas: 1920x1080, dark graphite, high-contrast white type.
- Accent: signal green for observed state, amber for authority, cyan for simulation provenance.
- Typography: system sans and system monospace for protocol values.
- Focal element: Construct/Gazebo simulation viewport on the left.
- Edge anchors: UMP event stream at right, chapter marker at top, truth boundary at bottom.
- Motion: restrained reveals, moving path traces, event pulses, and status transitions.
