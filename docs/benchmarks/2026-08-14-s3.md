## Invariant evidence

The runtime test suite exhaustively inserts restart and abort at each bounded lifecycle point: proposed, prepared, ready, transferring, and committed. Every non-committed durable record names the source as owner; committed records name the destination. Restart during transfer becomes `unknown`, requires inspection, and is not retry-safe. Restart after commit preserves destination ownership.

Multi-resource claims are sorted by stable resource ID and evaluated all-or-none. No failed request leaves a partial reservation. Reservation loss emits an affected-task notice and aborts pre-transfer handoffs or marks transferring handoffs unknown.
