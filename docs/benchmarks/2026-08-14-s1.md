## Fault matrix

The deterministic run rejected one duplicate packet, one incompatible major version, one expired credential, one stale state update, and one oversized 257-sample telemetry batch. One disappearing peer expired without affecting the other 18 peers in the observer's view.

Unit and CLI integration tests additionally verify authenticated identity mismatch rejection, heartbeat replay rejection, session replacement on reconnect, metadata publication authorization, and deny-by-default metadata enrollment.

## Runtime footprint

A continuous release-mode `umpd` process on macOS ARM64 measured 3,264 KiB resident memory and 0.0% CPU after five idle seconds. The release binaries measured 3,576,736 bytes for `umpd` and 4,442,816 bytes for `ump`. These are development baselines, not representative onboard hardware measurements.

## Platform validation

The current tree passed all Rust workspace tests and S1 under emulated Linux ARM64 using Rust 1.85.1:

```sh
docker run --rm --platform linux/arm64 \
  -e RUSTUP_TOOLCHAIN=1.85.1 \
  -v "$PWD:/work" -w /work rust:1.85-bookworm \
  sh -c '/usr/local/cargo/bin/cargo test --workspace -q && \
    /usr/local/cargo/bin/cargo run --release -q -p ump-sim --bin s1'
```

Native Linux and real-network measurements remain required before making deployment performance claims.
